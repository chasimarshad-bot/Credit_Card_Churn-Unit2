## Suggested project description

Credit card retention insights: an analysis of a historical customer snapshot using a validated Python ETL pipeline, three exploratory statistical hypotheses, a comparison of Logistic Regression and Random Forest, and an interactive Streamlit dashboard. Evaluation includes a majority baseline, separate training/validation/test partitions, precision/recall trade-offs and limitations. Findings describe recorded attrition and do not establish causation or proven future forecasting performance.
